# Sister's Cosmic Wish

Build a premium, highly interactive birthday celebration website based on the attached reference image.

The website is a magical, dreamy, cosmic birthday experience dedicated to a beloved sister. The visual style should closely follow the reference image: pastel pink, lavender, purple, blue, soft clouds, flowers, stars, glowing particles, elegant handwritten typography, cinematic transitions, glassmorphism cards, and magical cosmic effects.

IMPORTANT:

Do NOT make this as a simple static landing page.

Create a complete multi-section interactive experience where the user progresses through different scenes.

The website should feel like an interactive birthday story / digital experience.
